# Gallery photos & videos

Drop last year's Surabhi photos and videos into this folder. The site picks them up automatically.

- Photos: .jpg .jpeg .png .webp .avif
- Videos: .mp4 .webm (short clips, under ~15 MB each, play muted on loop)
- Order: files are sorted by name, so prefix them: 01-inauguration.jpg, 02-raaga-finale.mp4 ...
- Caption: taken from the file name, so 02-raaga-finale.mp4 shows "Raaga finale".
- Tip: resize photos to about 1600 px on the long side before adding them.
